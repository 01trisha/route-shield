## Русский

- Добавлен системный выбор приложений: `.app` на macOS и `.exe` на Windows. Перетаскивание также доступно.
- Для смены IP и ухода в сон можно отдельно выбрать экстренное или безопасное закрытие. Закрытие при уходе в сон по умолчанию выключено.
- При смене IP режим закрытия можно настроить на третьем шаге приветствия. Безопасный режим даёт приложению возможность сохранить изменения, но оно может остаться открытым.
- В меню появилась скрываемая строка о доступной версии. Она и системное уведомление ведут к кнопке скачивания в настройках.
- После обновления Route Shield показывает список изменений на выбранном языке.
- Автозапуск выделен в настройках, а рядом с приложениями в меню отображаются их иконки.
- Версия для Windows 11 x64 доступна для тестирования как бета. Есть установщик и ZIP со встроенным .NET.

## English

- Added a system file picker for `.app` bundles on macOS and `.exe` files on Windows. Drag and drop is also available.
- Closing on IP changes and on sleep can use separate emergency and safe modes. Closing on sleep is off by default.
- Choose the closing mode for IP changes on the third welcome step. Safe mode gives apps a chance to save changes, but they may stay open.
- The menu now has a dismissible update message. Clicking it or the system notification takes you to the download button in Settings.
- After an update, Route Shield shows the release notes in the selected language.
- Launch at sign-in has its own section, and the menu shows each app's icon.
- The Windows 11 x64 beta is available for testing. Both the installer and ZIP include .NET.
