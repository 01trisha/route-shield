# Route Shield для Windows (бета)

[English](README.md) · [macOS](../README.md)

Route Shield работает в области уведомлений Windows. Нажмите на значок рядом с часами, чтобы увидеть внешний IPv4, IPv6 и страну для каждого адреса. Перетащите `.exe` или ярлыки из Проводника. Кнопка **Выбрать приложение…** открывает окно выбора файлов `.exe`. Добавленные приложения отображаются сеткой с иконками и кнопками удаления.

Выберите приложение в меню Route Shield или создайте ярлык на рабочем столе, чтобы проверить соединение перед запуском. Прямой запуск доступен как обычно. Если включено закрытие при смене IP, Route Shield отслеживает и приложения, запущенные напрямую. При подтверждённой смене IP утилита сразу начинает закрывать приложения из списка и может отправить два уведомления. Первое сообщает о новом соединении, второе перечисляет приложения, завершение которых удалось подтвердить. При закрытии могут потеряться несохранённые данные.

В разделе **Основные → Закрытие приложений** можно отдельно выбрать режим при смене IP и при уходе в сон. Закрытие перед сном по умолчанию выключено. **Экстренное** быстрее разрывает соединения, но может привести к потере несохранённых изменений. **Безопасное** просит приложение закрыться штатно. Оно может ждать ответа, остаться открытым или не успеть завершиться до сна.

## Запуск

Нужна Windows 11 x64. Скачайте ZIP или установщик для текущего пользователя из [успешной проверочной сборки Windows](https://github.com/01trisha/route-shield/actions/workflows/windows.yml?query=branch%3Afeature%2Fwindows). Войдите в GitHub, скачайте **route-shield-windows-x64** в разделе **Artifacts** и распакуйте архив. Если выбрали ZIP, распакуйте его целиком и запустите `RouteShield.exe`. .NET входит в сборку. При первом запуске можно выбрать язык, настроить уведомления и выбрать, закрывать ли приложения при смене IP и в каком режиме. При обновлении переносной версии используйте ту же папку, чтобы ярлыки рабочего стола и автозапуска сохранили путь к программе.

Настройки и список приложений хранятся в `%LOCALAPPDATA%\Route Shield\settings.json` и сохраняются при обновлении. Файл можно открыть во вкладке **Основные**. Перед редактированием выйдите из Route Shield. Проверка обновлений доступна вручную и автоматически раз в сутки. Нажмите на строку внизу меню или системное уведомление, чтобы перейти к кнопке **Скачать обновление…** во вкладке **Основные**. Кнопка открывает страницу релиза на GitHub. Крестик скрывает строку для текущей версии. Системные напоминания повторяются примерно раз в двое суток.

При первом запуске после обновления окно **Что нового** показывает изменения на выбранном языке. Текст хранится в [RELEASE_NOTES.md](../RELEASE_NOTES.md).

## Сборка и проверка

Для сборки на Windows установите .NET 10:

```powershell
dotnet run --project windows/RouteShield.Tests -c Release
dotnet publish windows/RouteShield -c Release -r win-x64 --self-contained -o build/windows
```

[Сборка на GitHub](../.github/workflows/windows.yml) создаёт ZIP и установщик Inno Setup с отдельными SHA-256. Для бета-выпуска используйте тег вида `windows-v1.0.0-beta.1` и отметьте выпуск как prerelease. Проверка обновлений ищет теги Windows и файлы x64 с именами, которые формирует сборка.

Для IPv4 используется ipify, для IPv6 — ifconfig.me. Country.is определяет страну отдельно для каждого адреса. Проверки запускаются по сетевым событиям Windows, при выходе из сна и по резервному таймеру. Сбой запроса сохраняет последний успешный результат для сравнения. При раздельной маршрутизации Route Shield и выбранная программа могут выходить в сеть через разные адреса. До обнаружения смены IP приложение может успеть отправить трафик.

Бета отслеживает обычные `.exe` по пути к исполняемому файлу и поддерживает `.lnk`, которые на них ссылаются. Для пакетных приложений из Microsoft Store и процессов с повышенными правами потребуется отдельная интеграция. Показ баннеров зависит от настроек уведомлений Windows.
